# הקמה וחיבור — גיקלופדיה · תכנון תוכן

ההקמה לוקחת בערך 20 דקות, ועושים אותה פעם אחת. צריך שני חשבונות חינמיים, ושניהם לא דורשים כרטיס אשראי:
**Supabase** (מסד נתונים, קבצים והתחברות) ו-**GitHub** (קוד המקור והאתר).

> לא שולחים סיסמאות או מפתחות סודיים בצ׳אט. שני הערכים שמועתקים בשלב 4 (Project URL ו-Publishable key) ציבוריים מעצם הגדרתם: הם מוטמעים באתר עצמו, וההגנה על הנתונים נאכפת במסד הנתונים. את ה-Secret key ואת סיסמת מסד הנתונים לא מעתיקים לשום מקום.

---

## שלב 1 — פרויקט ב-Supabase

1. נכנסים ל-<https://supabase.com/dashboard> ונרשמים (אפשר עם GitHub).
2. **New project**:
   - Name: `geekclopedia-planner`
   - Database Password: לוחצים **Generate**, ושומרים את הסיסמה במנהל הסיסמאות. במערכת עצמה לא משתמשים בה.
   - Region: **Central EU (Frankfurt)**, האזור הקרוב ביותר לישראל.
   - Plan: **Free**.
3. מחכים כ-2 דקות עד שהפרויקט מוכן.

## שלב 2 — מסד הנתונים

1. בתפריט הצד: **SQL Editor** ← **New query**.
2. מעתיקים את **כל** התוכן של הקובץ `supabase/migrations/20261119000000_init.sql`, מדביקים ולוחצים **Run**. התוצאה הצפויה: `Success. No rows returned`.
3. פותחים שאילתה חדשה ומדביקים את התוכן של `supabase/setup-members.sql`. **מחליפים את שתי כתובות האימייל בכתובות האמיתיות של לירן ושל אלה**, באותיות קטנות, ולוחצים **Run**.

## שלב 3 — התחברות: רק לירן ואלה

1. **Authentication** ← **Sign In / Providers**: מכבים את **Allow new users to sign up** ולוחצים **Save**. מעכשיו אף אחד לא יכול להירשם בעצמו. גם אם ההגדרה תופעל בטעות, מסד הנתונים חוסם כתובת שלא מופיעה ברשימה משלב 2.
2. **Authentication** ← **Users** ← **Add user** ← **Create new user**. חוזרים על זה פעמיים, פעם ללירן ופעם לאלה:
   - Email: הכתובת מהשלב הקודם.
   - Password: סיסמה זמנית, לפחות 8 תווים.
   - מסמנים **Auto Confirm User**.
3. מוסרים לאלה את הסיסמה הזמנית בעל-פה או בהודעה פרטית. אחרי הכניסה הראשונה כל אחד מחליף סיסמה: עיגול המשתמש ← **שינוי סיסמה**.
4. בדיקה: ב-SQL Editor מריצים את השורה האחרונה של `setup-members.sql`. צריכות להופיע שתי שורות, ובשתיהן `linked = true`.

## שלב 4 — הערכים לחיבור האתר

**Project Settings** ← **API Keys** (או **Data API**). מעתיקים:
- **Project URL**, למשל `https://abcdefgh.supabase.co`
- **Publishable key** (מתחיל ב-`sb_publishable_`). אם הוא לא מופיע, מעתיקים את ה-`anon` `public` key.

לא מעתיקים את ה-**Secret key** או את ה-`service_role`.

## שלב 5 — GitHub והאתר

1. נכנסים ל-<https://github.com/new> ויוצרים מאגר חדש:
   - Name: `geekclopedia-planner`
   - **Public**. ב-GitHub Free האתר (GitHub Pages) עובד רק ממאגר ציבורי. מה שציבורי הוא **הקוד בלבד**: אין בו תוכן, קבצים או סיסמאות, והתוכן שלכם נשמר ב-Supabase מאחורי התחברות. אם חשוב לכם שגם הקוד יהיה פרטי, ראו "חלופה" בסוף.
   - לא מסמנים README. משאירים את המאגר ריק.
2. מעלים את הקוד: אומרים לקלוד את שם המאגר (למשל `liran/geekclopedia-planner`) והוא ידחוף אליו את הקוד. אפשר גם להעלות ידנית.
3. במאגר: **Settings** ← **Secrets and variables** ← **Actions** ← לשונית **Variables** ← **New repository variable**. יוצרים שני משתנים:
   - `VITE_SUPABASE_URL` = ה-Project URL
   - `VITE_SUPABASE_ANON_KEY` = ה-Publishable key
4. **Settings** ← **Pages** ← Source: **GitHub Actions**.
5. **Actions** ← **פרסום לאתר (GitHub Pages)** ← **Run workflow**. אחרי כ-2 דקות האתר זמין בכתובת
   `https://<שם-המשתמש>.github.io/geekclopedia-planner/`

## שלב 6 — כתובת האתר ב-Supabase (לאיפוס סיסמה)

**Authentication** ← **URL Configuration**:
- Site URL: כתובת האתר משלב 5, כולל `/` בסוף.
- Redirect URLs: מוסיפים את אותה כתובת.

## שלב 7 — בדיקה

1. נכנסים לאתר מהמחשב בתור לירן ומהנייד בתור אלה.
2. לירן יוצר תוכן ביום כלשהו בלוח, ובתוך כמה שניות התוכן מופיע אצל אלה.
3. מצרפים תמונה ופותחים אותה מהמכשיר השני.
4. מוחקים את תוכן הבדיקה: **העברה לארכיון** ← **ארכיון** ← **מחיקה לצמיתות**.
5. במסך **גיבוי** מורידים גיבוי ראשון ושומרים אותו.

## תחזוקה שוטפת

- **גיבוי:** פעם בחודש, מסך "גיבוי" ← "הורדת גיבוי מלא". שומרים את קובץ ה-zip ב-Google Drive או במחשב. בתוכנית החינמית אין גיבויים יומיים שאפשר להוריד מלוח הבקרה, ולכן הגיבוי באחריותכם.
- **אם האתר מציג "השרת לא זמין":** כנראה הפרויקט הושהה אחרי שבוע בלי שימוש. לירן נכנס ללוח הבקרה של Supabase ולוחץ **Restore project**. הנתונים נשמרים, ואפשר לשחזר פרויקט מושהה עד שנה ממועד ההשהיה.
- **שכחתם סיסמה:** כפתור "שכחתי סיסמה" שולח מייל רק לכתובות שחברות בצוות הארגון ב-Supabase, ובקצב של 2 מיילים בשעה לכל היותר. הדרך הבטוחה היא שלירן יריץ ב-SQL Editor את `supabase/admin-reset-password.sql`, עם סיסמה זמנית וכתובת מתאימה.
- **עדכון קוד:** כל דחיפה לענף `main` בונה ומפרסמת את האתר מחדש אוטומטית. הנתונים לא מושפעים.

## חלופה: קוד פרטי

אם רוצים שגם מאגר הקוד יהיה פרטי, אפשר לפרסם את האתר ב-**Cloudflare Pages**, שעובד במסלול החינמי גם עם מאגר פרטי. מחברים את המאגר, מגדירים Build command `npm run build` ו-Output `dist`, ומוסיפים את שני המשתנים מהשלב 5.3 כ-Environment variables. החלופה מוסיפה עוד חשבון לתחזוקה, ולכן היא לא ברירת המחדל.
